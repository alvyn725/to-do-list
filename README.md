# To Do List
This is a to do list project that i have been working on. 
It is ready for beta-testing, and is aimed at primary and secondary school students in Singapore.
No need for sign up and it is in dark mode.
The site is on https://alvyn725.github.io/to-do-list/

Built with HTML5, CSS3 and JavaScript ES6+ with localStorage

## Features
- [X] Do date and due date
- [X] Automatic prioritisation based on do and due dates
- [X] Subjects and status - currently only English, Math, Science, Mother Tongue, planning to add more in the future

## Roadmap to version 1
- [ ] Sidebar filters by subject and urgency status
- [ ] Export / Import JSON backup for saved tasks
- [ ] Custom subject tags

Please report any bugs or features you would like to see in the future at https://github.com/alvyn725/to-do-list/issues
